# 07 · Prototipo <br>

## Hipótesis del prototipo <br>

| | | <br>
|---|---| <br>
| **Qué vamos a construir** | Una base de datos para registrar y consultar los materiales entrantes y salientes del almacén, controlar las existencias y organizar los movimientos por cada área de trabajo. | <br>
| **Tipo de prototipo** | Base de datos para la gestión de inventario del almacén. | <br>
| **Usuario** | Orlando Morales, gerente general de Multy Security S.A.S. | <br>

**Hipótesis** <br>

> Creemos que Orlando Morales podrá mejorar el control del inventario de Multy Security S.A.S. si utiliza una base de datos donde se registren los materiales que entran y salen del almacén, se consulten las existencias y se identifiquen los movimientos por cada área de trabajo. <br>

**Sabremos que es cierto si:** durante una semana de prueba, los movimientos de entrada y salida de materiales quedan registrados y se puede consultar la información del inventario sin depender exclusivamente del conteo manual y físico.<br>

## Versión 0.1 <br>
**Qué tiene la v0.1:** <br>

1. Formulario para registrar los materiales que ingresan al almacén. <br>
2. Formulario para registrar las salidas de materiales. <br>
3. Registro de la cantidad de cada material. <br>
4. Identificación del área de trabajo relacionada con cada movimiento. <br>
5. Consulta de las existencias registradas en el almacén. <br>
6. Historial de entradas y salidas de materiales. <br>
